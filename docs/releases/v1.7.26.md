# Blogville v1.7.26 (2026-10-15)

## 바뀐 것

- 🕘 **지난 위치로 보기**: 📍로 찾은 위치를 이 브라우저에만 6시간 기억해서, 다음에 맛집 → 내 주변을 열면 [🕘 지난 위치로 보기] 한 번으로 바로 봐요. 위치는 서버에 저장하지 않아요.

- 🧳 **다른 지역 여행 글 빼기**: 식당 후기에 다른 도시 여행기("강릉 여행" 등)가 지나가듯 식당을 언급한 글은 빼요.
