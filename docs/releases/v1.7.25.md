# Blogville v1.7.25 (2026-10-15)

식당 후기에 엉뚱한 글이 섞이던 문제를 더 단단히 막았어요.

## 고친 것

- 🍽 "마피아"처럼 다른 뜻으로도 쓰이는 이름의 식당에 "마피아 게임"·"연극 <마피아>"·청년 축제·영화 글이 섞이던 것을 뺐어요.
  - 이름이 게임·연극·영화·공연 이름으로 쓰인 글은 빼요.
  - 식당 이름 바로 곁에 먹은 이야기(맛집·메뉴·피자 등)가 있거나, 글에 그 가게 도로명·전화번호가 그대로 있어야 그 식당 후기로 봐요.
  - "후기·방문·리뷰"처럼 어디에나 나오는 말, "사회"처럼 엉뚱하게 걸리던 말은 더 이상 먹은 이야기로 치지 않아요.
- 글을 열어 볼 때 본문에 그 가게 전화·도로명·지도가 있는지도 확인해요 (본문까지 확인한 글이 더 정확해요).
