# Blogville v1.7.35 (2026-10-15)

관리자가 회원에게 코인·경험치를 선물할 수 있고, 방금 본 화면으로 돌아가면 바로 보여요.

## 새로 생긴 것

- 🎁 **관리자가 코인·경험치를 줄 수 있어요**: 관리자 화면 → 👥 회원 → 회원의 [관리]를 열면 🪙 코인·⭐ 경험치 칸과 🎁 주기 버튼이 있어요. 받은 회원의 내역에는 "🎁 운영자 선물"로 보이고, 레벨이 오르면 레벨업 알림도 가요. 준 양과 전후 레벨은 📜 관리 기록에 남아요. 한 번에 코인 1,000,000·경험치 100,000까지 줄 수 있어요.

## 빨라진 것

- ⚡ **방금 본 화면으로 돌아가면 바로 보여요**: 마을 소식 → 인기 글 → 마을 소식처럼 30초 안에 다시 간 화면은 서버에 다시 묻지 않고 받아 둔 화면을 바로 보여 줘요. 글·댓글·공감·이웃 추가처럼 내가 바꾼 것은 그 자리에서 바로 반영돼요.
- 🗺 **사이트맵**: 검색엔진이 읽는 사이트맵을 10분 동안 기억해요(글 20만 개 시험 DB에서 210ms → 100ms).
