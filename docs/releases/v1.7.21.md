# Blogville v1.7.21 (2026-10-14)

식당 후기를 최근 1년 치 모두, 네이버 말고 다른 곳에서도 모아 보여 줘요.

## 한눈에

| | 바뀐 것 |
|---|---|
| 📅 1년 치 전부 | 식당 후기를 오늘부터 1년 안 글 모두 (10쪽 제한 없음) |
| 🌐 다른 곳도 | 네이버 블로그 + 티스토리·다음 블로그 + 다음 카페 |
| 🏷 출처별 보기 | [전체] [네이버 블로그] [티스토리·다음 블로그] [다음 카페] 단추, 카드에 출처 표시 |
| 🔥 블로그 수 | 요즘 뜨는 곳을 셀 때 다음·티스토리 글도 함께 세요 |

## 📅 1년 치 후기

- 식당 상세의 후기가 최신순으로, 1년 안 글을 모두 보여 줘요. 쪽 번호는 ‹ 1 … 4 5 6 … N › 한 줄이에요.
- 같은 글이 여러 곳에서 나오면 한 번만 보여 주고, 그 식당 이야기가 아닌 글·광고는 그대로 걸러요.

## 🌐 다른 곳 후기

- 카카오(다음) 검색으로 티스토리·다음 블로그·브런치 같은 블로그와 다음 카페 글을 찾아요. 제목·요약·사진과 원문 링크만 보여 줘요.
- 카페 글은 카페 회원만 볼 수 있는 경우가 있어요.
