# Blogville v1.7.37 (2026-10-16)

Safari에서도 📍 내 위치로 날씨·맛집을 볼 수 있고, 날씨 위젯의 미세먼지가 다시 보여요.

## 고친 것

- 📍 **Safari에서 내 위치가 잡혀요**: iPhone·Mac Safari는 위치를 잡는 데 오래 걸려 10초 만에 실패로 끝나곤 했어요. 이제 20초까지 기다리고, 못 잡으면 정밀 위치로 한 번 더 물어요. 날씨 위젯·🍽 맛집 내 주변·📍 내 동네 인기 모두 같아요.
- 🧭 **안 될 때 어디를 켜야 하는지 알려 줘요**: "권한이 꺼져 있음"과 "위치를 못 찾음"을 나눠 안내하고, iPhone은 설정 앱 → 개인정보 보호 및 보안 → 위치 서비스, Mac은 시스템 설정 → 개인정보 보호 및 보안 → 위치 서비스처럼 켜는 곳을 알려 줘요.
- ☀️ **날씨가 내 위치를 기억해요**: Safari는 위치 허락을 방문마다 다시 물어서 매번 블로그 도시 날씨로 돌아갔어요. 이제 한 번 쓴 내 위치(약 10km 단위)를 이 브라우저에 기억해 다음에 와도 바로 보여 줘요. "도시 날씨 보기"를 누르면 잊어요.
- 😷 **미세먼지가 다시 보여요**: 미세먼지 정보를 4초 만에 포기하고 30분 동안 빈칸으로 두던 것을, 8초까지 기다리고 못 받으면 5분 뒤 다시 받게 했어요.
